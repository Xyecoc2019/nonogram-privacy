# Nonogram — Privacy Policy

Статическая страница политики конфиденциальности для приложения «Nonogram»
(Android). Опубликована через GitHub Pages.

Адрес страницы: `https://<user>.github.io/nonogram-privacy/`

## Что внутри

- `index.html` — политика конфиденциальности, русский и английский в одной
  странице. Контактный email разработчика: `onerusnak@gmail.com`.

## Локальный просмотр

```bash
python -m http.server 8000
# затем открыть http://localhost:8000/
```

## Как обновлять

Файл `index.html` самодостаточен: стили встроены, внешних ресурсов нет,
шрифты системные. Достаточно отредактировать его и сделать `git push` —
GitHub Pages пересоберёт сайт автоматически.

При изменении набора собираемых данных, рекламных SDK или способов авторизации
политику нужно обновить одновременно с Data Safety Form в Google Play Console.
